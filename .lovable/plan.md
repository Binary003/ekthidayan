# Happy Birthday Muskan

## Experience
- Build one fast, mobile-first birthday story in a centered phone-width canvas, using the supplied crimson, maroon, rose, and gold direction.
- Begin with a playful gift screen where the button dodges four taps, then opens on the fifth and starts the supplied song.
- Continue through the timed letter, swipeable eight-photo memory carousel, five heartfelt qualities, and an interactive 23rd-birthday cake finale.
- Add replay, music controls, fullscreen photo viewing, portrait guidance, loading feedback, subtle haptics, and reduced-motion support.

## Content and assets
- Preserve every supplied line, caption, nickname rule, and the no-emoji rule.
- Store the eight uploaded photos and instrumental track as fast CDN assets; derive a small red-heart favicon locally.
- Keep image loading lightweight with lazy loading and soft placeholders.

## Technical details
- Implement as a fully static single route with React and Tailwind, using touch-friendly pointer and swipe interactions.
- Use CSS/SVG for the gift, cake, candles, hearts, petals, sparkles, smoke, and celebratory effects.
- Start audio only after the successful fifth tap, fade volume contextually, pause when hidden, and recover silently if unavailable.
- Add complete page metadata and verify the finished experience at phone and desktop sizes.
